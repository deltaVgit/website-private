Référence · à imprimer

Glossaire

Le langage canonique de Mon premier agent IA. Des définitions serrées pour réviser — pas un substitut aux leçons. Préférez ces termes dans chaque module.

Stack

LLM

Le modèle de langage qui planifie, rédige, et peut demander des outils. Il n’exécute pas, à lui seul, d’outils sur votre disque.

À éviter : « L’IA a écrit le fichier » sans nommer le harness

Agent

Cerveau + outils + boucle. Plus qu’une simple complétion de chat.

À éviter : Agent = n’importe quel chatbot ; Agent = les poids du modèle seuls

Harness

L’application qui fait tourner la boucle, assemble les messages, exécute les outils et applique les approbations. Ici : Hermes Desktop (+ gateway).

Runtime

La machine (et son isolation) où le harness et les outils s’exécutent. Préférez une machine dédiée.

Boucle et messages

Penser → Agir → Observer

Penser = le modèle planifie. Agir = le harness exécute l’outil ou la réponse finale. Observer = le résultat / l’erreur revient pour le prochain Penser.

À éviter : « La boucle vit uniquement dans le LLM »

Ops

Outil

Action structurée que le harness peut exécuter (lister un dossier, écrire un fichier, shell, …).

Compétence

Mode d’emploi / procédure empaquetée que l’agent peut charger — ce n’est pas exécuter un outil.

`SOUL.md`

Qui est l’agent : personnalité et limites strictes d’un profil. Pas les fichiers de règles d’un projet.

Machine dédiée

Machine-labo pour le cockpit de l’agent — pas l’endroit par défaut pour la banque, le SSO du travail et les photos de famille.

Reçu sur disque

Preuve sur disque que vous ouvrez hors ligne (ex. agency-receipt.md). Plus solide que le chat seul.

Partie II

Mémoire durable

Faits sur disque (MEMORY.md / USER.md) qui se rechargent à la session suivante. Ce n’est pas la fenêtre de contexte.

À éviter : Espérer qu’un long chat « saura » encore la semaine prochaine

Fenêtre de contexte

RAM de session pour le prompt actif. Peut se compresser ; ce n’est pas un carnet permanent.

Coffre Obsidian

Un dossier de notes (souvent Obsidian) que l’agent peut chercher — le troisième endroit où il range des choses.

Runbook cron

Prompt de tâche planifiée, autonome : machine, chemin, succès / échec, comme si l’agent avait amnésie.

Bot

Un profil Hermes nommé dans le roster Desktop : propre âme, modèle, mémoire, compétences et chat. Bot Mode est l’interface ; les fichiers vivent toujours sous ~/.hermes/profiles/<name>/.

À éviter : Bot = une passerelle Telegram ; Bot = un produit distinct des profils
