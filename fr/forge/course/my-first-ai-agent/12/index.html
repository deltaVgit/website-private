Backup

Le garder en vie : sauvegarder, mettre à jour, et monter en niveau — sans refaire la leçon 1.

Quoi sauvegarder

  • ·Le dossier Hermes home / profil (SOUL, mémoire, config, compétences que vous gardez)
  • ·Le coffre Obsidian et les AGENTS.md / contextes projet sur lesquels vous vous appuyez
  • ·.env tient les secrets — sauvegardez chiffré ; ne publiez jamais
Copiez les dossiers. C’est la sauvegarde. Le harness est portable parce que ce sont des fichiers.

Après une mise à jour : doctor ou health check, un chat de contrôle, gateway encore sur liste d’autorisation. Si un flag est renommé, Installation / Updating docs ↗ gagnent sur cette page.

Quand un agent ne suffit plus

Sous-agents ↗ : faire naître des aides pour un travail indépendant. Briefez-les comme des inconnus (échec, chemins, définition du « fini »). Le moins d’outils possible. Préférez des enfants moins chers et un parent fort pour la synthèse. Évitez de déléguer un travail interactif strictement séquentiel.

Profils : un second Hermes home (propre modèle, mémoire, gateway, persona) quand les rôles doivent rester isolés pour de bon — pas une aide temporaire.

Kanban / tableaux : quand le travail doit traverser les agents et survivre aux redémarrages. Utilisez les docs multi-agents officielles ↗ quand la douleur en série est réelle.

Les bases s’arrêtent à un harness solide. Multi-agents et plateformes en plus sont de la croissance optionnelle — pas un devoir de Partie I.

Carte de croissance — sept motifs

Vous pratiquez déjà outils et approbations. Ajoutez le reste quand une contrainte concrète apparaît.

  • ·1 Outils — jour 1 (fait)
  • ·2 Serveurs MCP — quand le travail traverse des services et des API externes
  • ·3 Pipeline séquentiel — jobs en plusieurs étapes via profils et wake gates
  • ·4 Parallèle — dispersion de recherche / délégation par lots
  • ·5 Routeurs — assigner par type à des profils spécialistes ou à un tableau
  • ·6 Humain dans la boucle — garder pour les actions à fort impact
  • ·7 Sous-agents dynamiques — l’orchestrateur fait naître de l’aide en cours de tâche

Kanban Desktop (croissance)

Le premier plugin officiel Hermes Desktop est Kanban : un tableau dans l’app pour le travail en plusieurs étapes, à travers les profils. Activez-le seulement après qu’un profil, les outils et les approbations tiennent. Ce n’est pas un devoir de Partie I.

  • ·Un plugin peut ajouter une page, une entrée de barre, des raccourcis, et des endpoints backend.
  • ·Les tableaux multi-profils ont besoin de SOUL + outils qui marchent par profil d’abord.
  • ·Écrivez votre propre plugin ou importez via le Desktop plugin SDK ↗ quand vous dépassez les défauts.
