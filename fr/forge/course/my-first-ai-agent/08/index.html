Le coffre Obsidian

Un dossier de vos propres notes, que l’agent peut lire et chercher.

00sur 03 sections derrière vous

Faites le coffre Obsidian, puis donnez-le

Un vault / coffre, ça sonne comme un logiciel. C’est un dossier de fichiers markdown — pas de base de données, pas d’API, pas de plugin. Rien à intégrer : vous faites le dossier, puis vous dites à votre agent où il est.

Obsidian est la fenêtre, pas le câblage. Vous l’installez pour vous — la vue graphe, les backlinks, la recherche instantanée. L’agent travaille sur les mêmes fichiers, qu’Obsidian soit ouvert ou fermé. C’est l’idée file over app ↗, rendue concrète.

L’ordre compte ici : faites le coffre d’abord, puis donnez-le à votre agent. Obsidian crée le dossier pour vous dans sa propre mise en place : rien à construire à la main.

Steps · tap the number to check0/4
  1. Téléchargez Obsidian ↗ et installez-le. Pas de compte nécessaire.
  2. Au premier lancement, choisissez Create new vault. Nommez-le second-brain.
  3. Choisissez où il vit, et notez le chemin — vous le donnerez à votre agent dans un instant. Quelque part simple comme votre dossier utilisateur, c’est l’idéal ; évitez un dossier synchronisé dans le cloud, ou vous réglerez des conflits de sync plus tard.
  4. Écrivez une courte note sur quelque chose de réel — une décision de cette semaine, des notes d’un appel. Juste une ; il vous faut quelque chose dedans qui vaille d’être trouvé.

C’est votre part. Hermes livre une compétence Obsidian déjà installée, donc il n’a besoin que du chemin — il lit OBSIDIAN_VAULT_PATH dans le fichier .env de votre Hermes home. Réglez-le et redémarrez Hermes.

Vérifiez maintenant qu’il peut lire : posez une question que seule votre note pourrait répondre. S’il vous cite vos propres mots, le câblage est bon.

Puis laissez-le écrire, la moitié la plus utile. Demandez-lui de vous installer l’endroit :

Apprenez-lui vos habitudes de classement

Ces trois dossiers sont notre suggestion, pas une règle d’Obsidian ni d’Hermes. Ils existent pour répondre à une question que tout système de notes finit par rencontrer — où est-ce que ça va ?

  • ·`inbox` — tout ce que vous avez jeté en vitesse et pas encore trié.
  • ·`sources` — ce que d’autres ont écrit : extraits, citations, papiers, liens.
  • ·`synthesis` — ce que vous avez conclu, dans vos mots. C’est le dossier qui devient précieux.

Renommez-les, enlevez-en un, utilisez votre propre schéma — ça ne change rien pour l’agent, tant que vous lui dites quel schéma vous avez choisi.
