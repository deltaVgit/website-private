Audit du budget de prompt

Mesurez le coût fixe d’une session vide ; coupez outils et skills ; re-mesurez.

00sur 03 sections derrière vous

Pourquoi ce lab

FIG

Une session vide charge encore le prompt système, l’index des skills, des instantanés de mémoire, les schémas d’outils, et AGENTS.md. Changer de modèle ne répare pas un budget fixe gonflé. Ce lab mesure et coupe.

Pour aller plus loin
  • Harness 06 — Dépense / coût fixe→
  • Harness 09 — Skills→

Audit

Steps · tap the number to check0/5
  1. Lancez hermes prompt-size (hors-ligne OK) ou l’audit budget / contexte Desktop s’il a un autre nom. Notez le total et les plus gros morceaux dans prompt-budget.md.
  2. Listez les toolsets actifs. Désactivez-en un que ce profil n’utilise jamais (hermes tools ou Desktop Tools).
  3. Listez les skills. Désinstallez ou désactivez une skill « pour plus tard ».
  4. Relancez l’audit. Écrivez les chiffres avant → après.
  5. Un chat d’une ligne : confirmez que l’agent marche encore pour une tâche simple.
Ne supprimez pas SOUL ni MEMORY pour gagner l’audit. Coupez d’abord les outils et skills inutiles.

Modèle prompt-budget.md

# prompt-budget.md Before: total […] · top slices: tools […] skills […] memory […] Cuts: toolset […] · skill […] After: total […] Still works: yes/no
