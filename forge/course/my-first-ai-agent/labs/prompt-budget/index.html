Prompt budget audit

Measure fixed empty-session cost; cut tools and skills; re-measure.

~20 min

Requires

Assumes

Primary model works. You can open Tools and Skills panels (or CLI hermes tools / hermes skills).

Why this lab

Empty sessions still load system prompt, skills index, memory snapshots, tool schemas, and AGENTS.md. Upgrading the model will not fix a bloated fixed budget. This lab measures and cuts.
