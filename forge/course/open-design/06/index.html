Models for design

Kimi builds structure. Imagine paints stills. Everything else is fallback.

20 min·Module 7 of 11

01Division of labor

Using one “best” model for everything is how bills spike and quality blurs. Split jobs: long-context structure and multi-file layout vs pixel generation.

JobFrontWhyFallback
Decks, HTML, DESIGN.md edits, multi-fileKimi (BYOK)Structure, long context, code-like layoutOD free / other strong text model
Stills, variants, moodboardsGrok ImagineFast visual explorationAny still API you already pay for
Tiny copy tweaksCheapest acceptable text modelSave the good model for hard layoutPrimary text model
Course rule: Kimi builds the artifact; Imagine paints the stills. General token/tool cost theory lives in My First AI Agent 06 — do not re-learn it here; only assign jobs to models.
