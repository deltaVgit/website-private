# Example profile tree (shape only)

Paths vary by OS. Shape is the lesson.

```
~/.hermes/                    # or Windows AppData equivalent
  profiles/
    default/                  # or your named profile
      SOUL.md
      MEMORY.md
      USER.md
      config.yaml             # name may differ by version
      .env                    # secrets — never publish
      skills/
      sessions/
      logs/
```

Backup = copy the profile folder + vault + encrypted .env offline.
